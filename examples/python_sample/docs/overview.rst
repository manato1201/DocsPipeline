概要
====

``sample_tool`` は、処理時間を測る小さなツール。DocsPipeline で Python のパッケージを文書化する流れの動作確認用で、
``docspipeline init`` で作った雛形のうえに、少しだけ文章を足している。

目的
----

* docstring (Google 形式、日本語) から API 文書を生成する。
* ``hou`` を使うコードも、Houdini なしで文書化する (``--hou``)。
* Mermaid の図を、ビルド時に画像へ変換する。

見るポイント
------------

* :doc:`api` は docstring から自動生成している。
* :doc:`design` の図は、``mmdc`` があれば画像に、無ければコードのまま表示される。

使うときの注意
--------------

``hou`` のスタブは何も実装していない。文書を作るためだけに使う。
