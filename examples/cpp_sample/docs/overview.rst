概要
====

``sample_engine`` は、文書を登録して語句で検索する、小さな C++ の索引。DocsPipeline で C++ を文書化する流れ
(Doxygen → Breathe → Sphinx) の動作確認用で、実際の RAGReel のコードではない。

目的
----

ヘッダーの Doxygen コメントから、API 文書を生成する。

見るポイント
------------

* :doc:`cpp` は、ヘッダーのコメントから自動生成している。関数名は、コードから読み取った名前がそのまま出る。
* Doxygen のコメントの書式の誤りは、Sphinx の警告になり、``-W`` でビルドが止まる。

使うときの注意
--------------

``doxygen`` 本体が要る。
